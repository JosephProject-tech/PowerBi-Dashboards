# 📊 HR Capstone Project | Employee Retention

## 📌 Project Overview

This project looks at employee data to see how employees movement and to spot trends between departments.

The dashboard gives a interactive view of employees who have left, how salaries are spread out, performance ratings, hours worked and how projects are assigned.

## 📈 Key Performance Indicators

| Metric | Value |
|:---|---:|
| Total Employees | 14,999 |
| Remaining Employees | 11,428 |
| Employees Left | 3,571 |
| Employees Leaving Rate | 23.8% |

## 🔍 Dashboard Analysis

- **Department-wise Salary:** Compares salary-related metrics across departments.
- **Employee Attrition:** Identifies departments with higher employee exits.
- **Performance Analysis:** Examines employee exits across performance rating groups.
- **Working Hours Analysis:** Compares employee exits across working-hour groups.
- **Project Distribution:** Compares the number of projects across departments.
- **Interactive Filtering:** Allows department-wise exploration using slicers.

## 💡 Key Observations

- Sales has the highest employee exits among the departments displayed.
- Employees in the above-80% performance group represent the largest exit count among the displayed performance groups.
- Sales has the highest number of projects among the displayed departments.
- The overall employee attrition rate is approximately 23.8%.
